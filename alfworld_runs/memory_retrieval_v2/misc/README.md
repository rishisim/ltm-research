# Miscellaneous Files - Memory Retrieval V2

This directory contains archived and auxiliary files that are not part of the current active workflow.

## Structure

### `old_runs/`
Archived experiment runs and agent code:
- `agents/` - Empty agents folder (previously unused)
- `memory_allocation_runs/` - Earlier memory allocation experiment runs
- `memory_agent_runs/` - Earlier memory agent test runs (including valid_unseen_test)

### `backups/`
Backup copies of important files:
- `knowledge_base_copy.csv` - Backup of knowledge base in CSV format
- `knowledge_base_copy.json` - Backup of knowledge base in JSON format

### `utilities/`
Helper scripts and tools:
- `extract_trajectories_csv.py` - Script to extract trajectories to CSV format

### `old_results/`
Previous or specialized result files:
- `run_summary_CR.json` - Earlier run summary (CR variant)
- `trajectories_dedicated_task.json` - Dedicated task trajectory logs
- `trajectories_dedicated_task_CR.json` - Dedicated task trajectory logs (CR variant)

## Active Files (Parent Directory)

The main `memory_retrieval_v2/` directory now contains only actively used files:
- `knowledge_base/` - Current knowledge base (main JSON, CSV, and learning counts)
- `results/` - Current retrieval results and run summaries
- `analysis/` - Analysis CSV files for evaluation
- `README.md` - Main documentation
