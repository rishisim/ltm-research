% ============================================================================
% ABSTRACT
% ============================================================================
\begin{abstract}
LLM-based agents are increasingly augmented with episodic memory, yet memory is not a universal enhancement: it helps when past experience transfers, and hurts when similarity retrieves non-transferable advice. We study this through a controlled comparison of ALFWorld (structured household tasks, fixed action grammar) and WebShop (open-ended e-commerce, free-form navigation), plus an SQL diagnostic gate that tests whether syntactic regularity alone is sufficient. Our memory-centric framework stores outcome-validated episodic experiences and retrieves them via proactive \emph{Context Retrieval} (CR) and on-demand hybrid \emph{Tool Retrieval} (TR). On ALFWorld, CR+TR improves over ReAct by up to $+19.4$pp, approaching Reflexion at one-third the step cost. On WebShop, the \emph{same} system degrades strict success by up to $-30.5$pp. On SQL, a GPT-5.4 gate shows smaller but consistent degradation: ReAct solves 43/50 tasks, while CR+TR solves 39/50. We attribute these outcomes to three transfer conditions: \emph{task compositionality}, \emph{action space regularity}, and \emph{learning transfer radius}. Episodic memory helps when all three are high; when any are weak, semantically plausible memories can become confident misdirection.
\end{abstract}
