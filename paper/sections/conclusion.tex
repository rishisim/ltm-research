\section{Conclusion}
\label{sec:conclusion}

This work provides evidence that validated episodic memory is a conditional transfer mechanism, not an automatic improvement for LLM agents.
In the final audited results, ALFWorld shows the clear positive case: CR+TR improves ReAct by $+14.9$pp and hard-negative retrieval substantially hurts.
SQL shows only narrow transfer, with a $+0.5$pp CR+TR gain and negative CR/hard-negative results.
ScienceWorld remains diagnostic negative evidence: neither the final 1-var KB nor the later 3-var density gate promotes CR+TR over ReAct and hard-negative controls.

We argue that task compositionality, action-space regularity, and learning transfer radius explain this pattern.
These properties should be treated as diagnostic criteria rather than universal predictors.
Future work should test additional models and domains, develop retrieval gates that estimate transferability before injecting memory, and improve validation signals so that denser memories become more useful rather than merely more numerous.
