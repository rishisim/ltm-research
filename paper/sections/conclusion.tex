\section{Conclusion}
\label{sec:conclusion}

This work provides evidence that episodic memory is not a universal enhancement for LLM-based agents. Through a controlled study applying an identical memory system to ALFWorld and WebShop, we observe that the same retrieval mechanisms produce a ${\sim}47$pp swing in effect: up to $+19.4$pp improvement versus $-30.5$pp degradation. SQL adds a focused diagnostic: even in a regular action language, CR+TR falls from 43/50 to 39/50 when near-miss memories alter brittle semantic policies. Across these settings, irrelevant memories can cause \emph{less} harm than semantically ``relevant'' ones, suggesting confident misdirection rather than noise injection as the failure mode.

We attribute this divergence to three structural properties: task compositionality, action space regularity, and learning transfer radius. The practical thesis is direct: memory helps when all three support transfer; when they do not, retrieval should be gated, filtered, or replaced by intra-task correction. Future directions include adaptive memory gating that suppresses retrieval when transfer confidence is low, validation on additional domains and models, ScienceWorld as a planned high-transfer orthogonal test, and memory filtering strategies that assess transferability before injecting retrieved content.
