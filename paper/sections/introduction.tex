\section{Introduction}

LLM-based agents are increasingly augmented with memory systems that store prior experience and retrieve it during future tasks.
This design is appealing: if an agent has already corrected a failure once, the correction should be reusable later.
Yet this premise hides a central question: \emph{when does validated memory actually transfer?}

We study this question using a single memory framework across three final audited settings: ALFWorld~\citep{shridhar2021alfworld}, SQL query generation, and ScienceWorld~\citep{wang2022scienceworld}.
The framework extracts issue--learning pairs from successful Reflexion~\citep{shinn2023reflexion} training trajectories, retains validation metadata, and injects those memories at inference time through Context Retrieval (CR), Tool Retrieval (TR), or both.
All final evaluations use the same base ReAct~\citep{yao2023react} agent, Gemini 2.5 Flash, train-only knowledge bases, and hard-negative retrieval controls.

The results are conditional rather than universal.
ALFWorld is the clean positive case: CR+TR improves success from $67.9\%$ to $82.8\%$ on 134 held-out validation-unseen tasks, a $+14.9$pp gain.
The hard-negative control falls to $55.2\%$, which supports the interpretation that relevant retrieved memory is doing useful work rather than merely adding more prompt text.
SQL is a narrow-transfer diagnostic: CR+TR reaches $92.0\%$ success versus $91.5\%$ for ReAct, while CR alone and hard-negative retrieval both hurt.
ScienceWorld is a diagnostic negative case: ReAct remains best in the final audit at $30.0\%$ success, CR+TR averages $27.8\%$, and hard-negative CR+TR matches or exceeds CR+TR on the headline success metric.

These outcomes motivate a transfer-radius view of memory-augmented agents.
Validated memories help when environments contain reusable procedures and when retrieval relevance aligns with those reusable structures.
They are weak or harmful when retrieved memories are too narrow, when task structure changes faster than the memory can generalize, or when increased memory density does not improve retrieval alignment.
A post-hoc but pre-registered ScienceWorld density gate strengthens this interpretation: expanding the ScienceWorld training knowledge base to three variations per category improved some raw numbers, but still did not promote ScienceWorld because CR+TR underperformed same-run ReAct on mean success and reward, while hard-negative retrieval matched or beat CR+TR on success.

In summary, our contributions are:
\begin{enumerate}
    \item A \textbf{final audited evaluation} of validated episodic memory across ALFWorld, SQL, and ScienceWorld using train-only trials7 knowledge bases, held-out evaluation, and hard-negative controls.
    \item \textbf{Evidence for conditional transfer}: a strong ALFWorld gain ($+14.9$pp), a narrow SQL gain ($+0.5$pp), and a ScienceWorld non-promotion where memory density alone is insufficient.
    \item A \textbf{diagnostic framing} based on task compositionality, action-space regularity, and learning transfer radius, explaining when CR and TR should be expected to help, fail to add, or mislead.
\end{enumerate}
