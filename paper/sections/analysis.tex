\section{Analysis and Discussion}
\label{sec:analysis}

We trace the divergence between environments to three structural properties and synthesize them into a diagnostic framework. SQL then probes an important boundary case: high syntactic regularity with brittle semantic transfer.

% ----------------------------------------------------------------------------
\subsection{Task Compositionality}
\label{sec:compositionality}

ALFWorld tasks decompose into shared sub-goal phases (\textsc{Search} $\rightarrow$ \textsc{Acquire} $\rightarrow$ \textsc{Transform} $\rightarrow$ \textsc{Place}) that recur across task types, so a modest set of phase-specific learnings covers a combinatorially large task space. WebShop tasks are monolithic: each targets a unique product through a unique catalog path with no shared sub-task decomposition. This explains why CR yields $+15.7$pp on ALFWorld but $-29$pp on WebShop, and why the hard-negative paradox emerges: in WebShop, obviously irrelevant retrievals cause less harm than plausible-looking but non-transferable ones.

\paragraph{Principle.} Episodic memory is most effective when tasks share compositional sub-task structure.

% ----------------------------------------------------------------------------
\subsection{Action Space Regularity}
\label{sec:action-space}

ALFWorld's fixed grammar of ${\sim}$15 verb templates ensures that learned action sequences generalize across tasks. WebShop's action space is syntactically simple but combinatorially vast: free-form search queries and dynamically generated page elements mean that specific navigation paths never recur. TR's issue-level guidance accordingly helps in ALFWorld ($+8.2$pp unseen) but hurts in WebShop ($-21.5$pp).

\paragraph{Principle.} Episodic memory is most effective when the action space is constrained and regular.

% ----------------------------------------------------------------------------
\subsection{Learning Transfer Radius}
\label{sec:transfer-radius}

We define the \emph{learning transfer radius} as the number of distinct future tasks that benefit from a single learned experience. In ALFWorld, a learning like ``open the container before taking an object'' applies to dozens of tasks across multiple types (high radius). In WebShop, each learning is tied to a unique product (radius near zero). The empirical signature is visible in ALFWorld's stronger unseen-split gains ($+19.4$pp vs.\ $+16.4$pp on seen), indicating effective cross-task generalization.

\paragraph{Principle.} Episodic memory is most effective when the learning transfer radius is high.

% ----------------------------------------------------------------------------
\subsection{SQL: Regular Syntax, Brittle Semantics}
\label{sec:sql-diagnostic}

SQL initially appears favorable for episodic memory because its action space is constrained by a formal grammar. The diagnostic gate shows why this is insufficient. SQL memories often transfer at the level of syntax while failing at the level of denotation: a plausible prior learning can change whether duplicate rows are preserved, whether a join should include zero-count entities, whether exclusion applies to rows or grouped entities, which output columns the grader expects, or whether literal date strings should be normalized.

The strongest regressions are near-miss transfers. In one count query, memories about empty tables and count verification push the agent toward a left join, adding zero-concert stadiums that the reference query excludes. In another, a memory about countries that do not speak English transfers to TV-channel rows and collapses valid duplicate \texttt{(aspect ratio, country)} rows with \texttt{DISTINCT}. A third case adds a plausible explanatory \texttt{note} column even though the task asks only for death and injury values. These are not syntax failures; they are semantic policy shifts with large reward consequences.

The SQL hard-negative control performs closer to ReAct than CR+TR (41/50 vs.\ 39/50), echoing the WebShop pattern at smaller scale. Irrelevant memories are often easier to ignore than adjacent memories that look applicable but carry the wrong latent policy. SQL therefore strengthens the framework rather than weakening it: action space regularity is necessary but not sufficient. Memory helps when regular actions are embedded in compositional tasks whose learnings have broad transfer radius.

\paragraph{Principle.} Syntactic regularity does not guarantee memory transfer; the reusable unit must also preserve the task's semantic policy.

% ----------------------------------------------------------------------------
\subsection{Efficiency--Accuracy Trade-off}
\label{sec:efficiency}

Figure~\ref{fig:accuracy-cost} plots task success against computational cost (steps per task) on held-out splits, revealing a key practical distinction. On ALFWorld, CR+TR occupies an efficient frontier: it achieves near-Reflexion accuracy ($+19.4$pp vs.\ $+21.6$pp) at roughly one-third the step cost (${\sim}$23 vs.\ ${\sim}$79 steps/task), making it the preferred choice when compute budgets are constrained. On WebShop, memory variants shift the agent into a strictly dominated region: strict success degrades without any compensating reduction in cost. Reflexion improves success in both environments but consistently incurs 3--4$\times$ the baseline step cost.

When all three properties favor transfer, memory provides substantial gains; when they do not, retrieved experiences can actively mislead the agent. Before deploying a memory system, practitioners should assess their target environment along these dimensions: task compositionality, action space regularity, and learning transfer radius. When these properties are unfavorable or mixed, alternatives such as intra-task self-correction or memory systems with explicit transfer gating may be more appropriate.
